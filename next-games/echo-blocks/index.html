How to play 🎶

  1. 1Listen. The blocks light up and sing a melody, one note at a time. Each block has its own colour, shape and pentatonic note.
  2. 2Echo it back. Tap the blocks in the same order — on screen, or with keys 1–4.
  3. 3Grow the tune. Every round adds one more note, and the melody gets faster every 5 rounds. Each correct note is +10 points; finishing a round earns a bonus.
  4. 4Stay in tune. Easy mode forgives one wrong note (the melody plays again). Strict Mode ends the run on the first mistake. In Free Play, compose your own tune and share it as an ECHO code!

Pause anytime with P or the Pause button. Restart with R.
